# NeuroDrift Ultimate (Browser)

WebAudio binaural beats + continuous morphable noise (White → Pink) with:
- Brainwave Frequency slider
- Carrier Tone slider
- Noise Color slider (White → Pink)
- Master Volume slider
- Noise Volume slider
- Session Time slider
- Auto Sweep button
- Binaural Mode button
- Start Session button

Preset buttons **Sleep / Meditate / Focus** are preserved.

## Dev
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## GitHub Pages
Settings → Pages → Source: GitHub Actions, then push to `main`.
